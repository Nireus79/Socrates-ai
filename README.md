# Socrates

A philosopher you can ask anything: an artificial Socrates that examines your question with you by the Socratic method, and helps with
suggestions when you cannot answer. Built from the code of [Moly](https://github.com/Nireus79/Moly): browser extension (Chrome, Edge, Firefox),
desktop (Windows, Linux, macOS) and Android.

Status: planning. See [docs/PLAN.md](docs/PLAN.md).

The earlier Python project that lived in this repository (a Socratic assistant for software projects, version 0.1.1) was removed on
2026-10-22. It remains in the git history. The research prototype is [Nireus79/Socrates](https://github.com/Nireus79/Socrates).
