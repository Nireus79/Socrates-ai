Android

Android 7 or newer. Install it from F-Droid once it is listed there, or download the signed APK from the releases page and open it (your phone asks once to allow installing from your browser). Closing the app stops its engine.

Releases page

Linux

Download the Linux archive, unpack it and run socrates-desktop. It needs GTK 3 and WebKitGTK 4.1 (libgtk-3-0, libwebkit2gtk-4.1-0).

Releases page

Windows

Download the Windows archive, unpack it and run socrates-desktop.exe. The beta is not signed, so Windows may say "Windows protected your PC": choose "More info", then "Run anyway". It needs the WebView2 runtime (included in Windows 11). The Windows build has not been run by its author yet.

Releases page

Remove Socrates

Close it and delete the folder you unpacked it into. Your conversations and profiles stay in the .socrates folder of your user folder; export what you want to keep first (Settings), then delete that folder too. On Android, uninstalling the app removes everything.

There is no macOS build.
