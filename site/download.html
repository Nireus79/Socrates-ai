Scoop (Windows)

If you use Scoop, open a terminal and run these two lines. It needs the WebView2 runtime, which is part of Windows 11.

scoop bucket add socrates https://github.com/Nireus79/scoop-socrates

scoop install socrates

Obtainium

If you use Obtainium, add https://github.com/Nireus79/Socrates-ai as a new app and it installs and updates the signed APK from the releases page. Turn on "Include prereleases", because the beta releases are marked as pre-releases.

Android

Android 7 or newer, on 64-bit ARM phones (almost every phone made after 2017). Download the signed APK and open it (your phone asks once to allow installing from your browser). Closing the app stops its engine.

Linux

For Intel and AMD 64-bit computers (there is no ARM build yet). Download the Linux archive, unpack it and run socrates-desktop. It needs GTK 3 and WebKitGTK 4.1 (libgtk-3-0, libwebkit2gtk-4.1-0).

Download for Linux All releases

Windows

For Intel and AMD 64-bit computers (there is no ARM build yet; Windows on ARM may run it through its own emulation, which has not been tried). Download the Windows archive, unpack it and run socrates-desktop.exe. The beta is not signed, so Windows may say "Windows protected your PC": choose "More info", then "Run anyway". It needs the WebView2 runtime (included in Windows 11). The author has checked the Windows build on a Windows computer.

Download for Windows All releases

macOS

Download the macOS archive, unpack it and drag Socrates.app to Applications. The beta is not notarised by Apple, so the first start is refused: open System Settings, Privacy & Security, and choose "Open Anyway". The author has not run the macOS build on a Mac yet, so it may have problems; please report them.

How to get a key

Socrates talks to Claude or OpenAI with a key that belongs to you. A ChatGPT or Claude chat subscription does not include one. Create an account with a provider, add a small credit and a spending limit, and make a key: Claude keys or OpenAI keys. The app shows the same steps and pastes the key into an encrypted store on your device.

Remove Socrates

Close it and delete the folder you unpacked it into. Your conversations and profiles stay in the .socrates folder of your user folder; export what you want to keep first (Settings), then delete that folder too. On Android, uninstalling the app removes everything.
